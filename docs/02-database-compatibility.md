   - 更新记录并验证影响行数；
   - 包含长文本、特殊字符、日期时间等完整写入；

5. **唯一约束校验**：重复插入触发 `PDOException`，错误捕获准确。
6. **分页与批量插入**：
   - 批量 `INSERT` 批量入库；

**MySQL POC 结论**：全项通过（10/10 项），达到生产级功能支持标准。

## 2. KingbaseES POC 兼容性分析与准备 (标记：待在目标机环境实际联调)

根据金仓官方架构与 PHP 驱动生态：
1. **驱动模式**：
   - **模式 A (推荐兼容模式)**：KingbaseES V8/V9 支持原生兼容 PostgreSQL 协议，可在开启 `ora_func_style` 或标准 PG 模式下使用 PHP `pdo_pgsql` 直接连接与执行。
   - **模式 B (原生专有驱动)**：人大金仓提供的官方 `pdo_kdb` 扩展（随 Linux 安装包提供）。
2. **当前环境驱动状况**：
   - 当前 PHP 8.0 环境已内置并启用 `pdo_pgsql` 与 `pgsql` 扩展，底层基础连接协议层已具备；
   - 本地开发机当前未部署 KingbaseES 服务端实例，标记为：**“接口与适配层已完备，真实 KingbaseES 服务端待目标环境联调验证”**。
3. **关键方言差异与适配层规范**：
   - **标识符引用**：MySQL 使用反引号 `` ` ``，KingbaseES 使用双引号 `"`。
   - **自增主键**：MySQL 使用 `AUTO_INCREMENT`，KingbaseES 使用 `BIGSERIAL` / `SERIAL` 或 `GENERATED BY DEFAULT AS IDENTITY`，适配层需提供序列恢复（`setval`）工具。
   - **长文本类型**：MySQL 为 `TEXT` / `LONGTEXT`，KingbaseES 为 `TEXT`。
   - **布尔类型**：MySQL 映射为 `TINYINT(1)`，KingbaseES 为原生 `BOOLEAN`。
   - **时间戳与默认值**：兼容 `CURRENT_TIMESTAMP`。
   - **分页语法**：两者均支持 `LIMIT ... OFFSET ...`。
