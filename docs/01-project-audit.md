## 3. 兼容性与运行风险分析

1. **Windows 环境下的 Webman 进程机制**：
   - Webman 在 Windows 环境下采用单进程/开发模式运行（无 `pcntl` / `posix`），生产 Linux 部署使用多进程守护。
   - 适配层必须同时满足 CLI 脚本执行、Windows 调试以及 Linux 多进程守护环境下的数据库连接生命周期管理。
2. **KingbaseES 驱动兼容模式**：
   - 人大金仓 KingbaseES 原生具备 PostgreSQL 兼容模式，可通过 `pdo_pgsql` 连接；同时预留国产数据库驱动扩展接口。
   - 当前开发机未安装本地 KingbaseES 实例，将先完成接口设计、方言生成器、Schema 映射及单元验证套件，严谨标注 POC 验证结论。
3. **数据库切换安全性**：
   - 切换需要维护窗口与连接重载机制，不能直接在正在处理并发写入的过程中无序切换。
